# Jiayang Wang's personal website

A GitHub Pages website built with Jekyll and the Academic Pages theme.

Website: https://jiayangwang0612.github.io

## Editing content

| Content | File |
| --- | --- |
| Biography, research interests, and recent activities | `_pages/about.md` |
| Sidebar, contact details, and site settings | `_config.yml` |
| Navigation menu | `_data/navigation.yml` |
| Research listing | `_pages/portfolio.html` (displayed at `/research/`) |
| Network research project | `_portfolio/portfolio-1.md` |
| Publication listing | `_pages/publications.md` |
| Network metrics preprint | `_publications/2026-06-07-network-metrics.md` |
| Conference presentations and professional development | `_pages/experience.md` |
| Teaching entries | `_teaching/` |
| Personal images and research figure | `images/` |
| Small layout refinements | `_sass/_custom.scss` |

Teaching entries use an ISO date such as `2024-01-01` for sorting and a separate `semester` field such as `Spring 2024` for display. The sorting date is not a claimed course start date. Keep both fields in future teaching entries.

To add a publication, create a Markdown file in `_publications/` following the existing entry. Use `category: preprints` for preprints. Other categories appear in a separate section. Only label a paper as published in a journal once it has been published there.

The homepage contains a short, manually maintained list of recent activities. Update it alongside the detailed Experience or Publications pages when adding new work.

## Local preview

With Ruby and Bundler installed, run these commands in this folder:

```bash
bundle install
bundle exec jekyll serve
```

Open `http://localhost:4000`. Restart Jekyll after editing `_config.yml`.

For a production build:

```bash
bundle exec jekyll build
```

The generated `_site/` folder and local dependency folders should not be committed. The XML sitemap is generated by `jekyll-sitemap`; do not add a manually maintained `sitemap.xml` to the source.
